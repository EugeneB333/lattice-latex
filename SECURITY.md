# Reporting security issues

Please report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/EugeneB333/lattice-latex/security/advisories/new).
Include a minimal reproduction, affected commit, and likely impact. Do not post
API keys or private LaTeX documents in a public issue.

Lattice is currently pre-release software. Security fixes target the latest
`main` branch; older snapshots do not have a separate maintenance policy.
